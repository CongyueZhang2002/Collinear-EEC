\section{Purpose of this report}

This is the companion test report to \texttt{main.tex}. The main report
formulates the physics problem and numerical method; this document isolates
the numerical evidence and states what that evidence does not establish.

The solver evolves a two-component jet function,
\[
  \Jvec(b,\mu)=\bigl(J_q(b,\mu),J_g(b,\mu)\bigr),
\]
where the two entries describe the quark and gluon channels. A comparison
between several grid sizes is useful, but grid convergence alone does not
establish that all grids are approaching the correct equation. A solver can
converge reproducibly to the wrong answer if, for example,
\begin{itemize}[leftmargin=1.5em]
  \item the quark--gluon channels are transposed;
  \item a plus distribution or delta-function term has the wrong sign;
  \item forward evolution is correct but backward evolution is not;
  \item the time integrator has the wrong order;
  \item or the treatment of the finite \(b\) boundary changes the equation.
\end{itemize}

For that reason, this report uses two complementary diagnostics with known
continuum behavior:
\begin{enumerate}[leftmargin=1.5em]
  \item an artificial local kernel that isolates part of the time-evolution
  code;
  \item a physical momentum-conservation mode that checks the QCD kernels and
  exposes finite-domain effects.
\end{enumerate}

\section{The equation and the numerical domain}

\subsection{Continuum evolution}

The continuum equation is
\begin{equation}
  \frac{\partial}{\partial\ln\mu^2}\Jvec(b,\mu)
  =
  \int_0^1 \dd y\,y^2\,
  \Jvec\left(\frac{b}{y},\mu\right)\Pmat(y,\mu),
  \label{eq:continuum-rg}
\end{equation}
where \(\Pmat\) is the time-like splitting matrix. The jet function is written
as a row vector, so the component equations are
\begin{align}
  \partial_t J_q
  &=
  \int_0^1 \dd y\,y^2
  \left[
    J_q(b/y,t)P_{qq}(y,t)
    +J_g(b/y,t)P_{gq}(y,t)
  \right],
  \\
  \partial_t J_g
  &=
  \int_0^1 \dd y\,y^2
  \left[
    J_q(b/y,t)P_{qg}(y,t)
    +J_g(b/y,t)P_{gg}(y,t)
  \right],
\end{align}
with \(t=\ln\mu^2\).

The boundary condition is not given at one common value of \(\mu\). Instead,
each value of \(b\) has its own starting scale,
\[
  \mu_*(b)=\frac{b_0}{b_*(b)},\qquad
  t_*(b)=\ln\mu_*^2(b).
\]
The boundary therefore forms a curve in the \((\ln b,t)\) plane. The numerical
solution above this curve is obtained by forward evolution. The solution below
the curve is obtained by backward evolution.

\subsection{Lattice approximation}

The code uses a uniform lattice in
\[
  \ell=\ln b,
\]
and samples \(u=-\ln y\) with the same spacing. This makes every shifted point
\(\ell+u\) land exactly on another lattice point, so no interpolation is needed
inside the convolution.

The numerical lattice is finite. If \(b/y\) lies above the largest stored
value \(b_{\mathrm{grid,max}}\), the code sets the jet function to zero:
\begin{equation}
  \Jvec(b>b_{\mathrm{grid,max}},t)=0.
  \label{eq:zero-closure}
\end{equation}
Equation~\eqref{eq:zero-closure} is called the \emph{zero closure}. It is a
physical approximation, not merely an implementation detail. It must therefore
be distinguished from errors in the time integrator.

For diagonal plus distributions, a sharp closure also requires
\(\Jvec(b_{\mathrm{grid,max}},t)\) itself to be negligible. Otherwise the
shifted real term is set to zero immediately below \(y=1\), while the endpoint
self-subtraction remains. This discontinuity produces logarithmic sensitivity
to the first lattice spacing.

\section{Test 1: exactly solvable local evolution}

\subsection{Logic of the test}

The first test removes the nonlocal convolution and replaces the physical
kernel by
\begin{equation}
  \Pmat(y)=
  \begin{pmatrix}
    c_q & 0\\
    0 & c_g
  \end{pmatrix}
  \delta(1-y).
  \label{eq:local-kernel}
\end{equation}
Because the delta function selects \(y=1\), the shifted argument \(b/y\)
equals \(b\). Each lattice node then obeys an independent ordinary
differential equation,
\begin{equation}
  \partial_t J_q=c_qJ_q,\qquad
  \partial_t J_g=c_gJ_g.
\end{equation}
If the boundary value at a particular \(b\) is imposed at \(t_*(b)\), the exact
solution on either side of the boundary is
\begin{align}
  J_q(b,t)
  &=J_q\bigl(b,t_*(b)\bigr)
    \exp\left[c_q\bigl(t-t_*(b)\bigr)\right],
  \label{eq:exact-local-q}\\
  J_g(b,t)
  &=J_g\bigl(b,t_*(b)\bigr)
    \exp\left[c_g\bigl(t-t_*(b)\bigr)\right].
  \label{eq:exact-local-g}
\end{align}

This test is intentionally not a QCD test. It answers a narrower question:
\begin{quote}
Does the code evolve a known local differential equation correctly from a
\(b\)-dependent boundary line, both upward and downward in \(t\)?
\end{quote}

The calculation used
\[
  0.5\le b\le2.0,\qquad b_*(b)=b,
\]
\[
  J_q\bigl(b,t_*(b)\bigr)=1+0.2b,\qquad
  J_g\bigl(b,t_*(b)\bigr)=0.7+0.1b,
\]
with \(c_q=0.4\) and \(c_g=-0.3\). Thus \(t_*(\ell)\) is affine and the time
grid is uniform. Every stored value was compared with
Eqs.~\eqref{eq:exact-local-q} and \eqref{eq:exact-local-g}. The reported RMS
error is
\begin{equation}
  \epsilon_{\mathrm{RMS}}
  =
  \sqrt{
    \frac{1}{N_{\mathrm{values}}}
    \sum_k
    \left(
      \frac{J_k^{\mathrm{num}}}{J_k^{\mathrm{exact}}}-1
    \right)^2
  }.
  \label{eq:rms-relative}
\end{equation}

mixing, a nonlinear \(b_*\) curve, or every midpoint construction used by the
physical lower-region solve.

\section{Test 2: the physical momentum-conservation diagnostic}

\subsection{Why a power of \texorpdfstring{\(b\)}{b} simplifies the convolution}

Consider a trial function
\begin{equation}
  \Jvec(b,t)=b^\nu\bm v(t),
  \label{eq:power-mode}
\end{equation}
where \(\bm v\) contains the quark and gluon coefficients. The shifted
function is
\[
  \Jvec(b/y,t)=b^\nu y^{-\nu}\bm v(t).
\]
Substituting this expression into Eq.~\eqref{eq:continuum-rg} gives
\begin{equation}
  \partial_t\Jvec(b,t)
  =
  b^\nu\bm v(t)
  \int_0^1\dd y\,y^{2-\nu}\Pmat(y,t).
\end{equation}
The integral is a Mellin moment of the splitting matrix. In the standard
notation,
\begin{equation}
  N=3-\nu,\qquad
  \bm\Gamma(N,t)
  =
  \int_0^1\dd y\,y^{N-1}\Pmat(y,t).
  \label{eq:mellin-moment}
\end{equation}
Thus a nonlocal convolution in \(b\) becomes multiplication by a
two-by-two matrix.

\subsection{Why \texorpdfstring{\(J_q=J_g=b\)}{Jq = Jg = b} should not evolve}

Choose \(\nu=1\), so \(N=2\). The \(N=2\) moment measures the total momentum
carried through a splitting. A parton splitting can redistribute momentum
between quarks and gluons, but it cannot create or destroy total momentum.
This is the momentum sum rule.

For the LO kernels implemented in the code,
\begin{equation}
  \bm\Gamma^{(0)}(2)
  =
  \begin{pmatrix}
    -32/9 & 10/3\\
     32/9 & -10/3
  \end{pmatrix}.
  \label{eq:lo-moment-matrix}
\end{equation}
The row vector \((1,1)\) is a left zero-eigenvector:
\begin{equation}
  (1,1)\bm\Gamma^{(0)}(2)=(0,0).
  \label{eq:zero-eigenvector}
\end{equation}
Combining Eqs.~\eqref{eq:power-mode} and \eqref{eq:zero-eigenvector} gives the
special continuum solution
\begin{equation}
  J_q(b,\mu)=J_g(b,\mu)=b,
  \label{eq:stationary-solution}
\end{equation}
independent of \(\mu\). The boundary function for the numerical test is
therefore simply
\begin{equation}
  \Jvec\bigl(b,\mu_*(b)\bigr)=(b,b).
\end{equation}

At the continuum level this is a useful physical diagnostic. A swap between
\(P_{qg}\) and \(P_{gq}\), an incorrect delta coefficient, or an incorrect
plus-distribution subtraction generally destroys the cancellation in
Eq.~\eqref{eq:zero-eigenvector}. Its realization on the finite lattice needs
the separate closure qualification discussed below.

\subsection{Direct test of the implemented splitting kernels}

Before evolving on a lattice, the \(N=2\) moments were integrated directly
from the implemented fixed-\(n_f=5\) splitting functions. The coupling was
set to \(\as=\alpha_s/(4\pi)=0.01\). The two quantities that must vanish are
\begin{equation}
  \Gamma_{qq}(2)+\Gamma_{gq}(2),
  \qquad
  \Gamma_{qg}(2)+\Gamma_{gg}(2).
\end{equation}

\subsection{Why the lattice result is not exactly stationary}

Equation~\eqref{eq:stationary-solution} is exact when the kernels obey the
momentum sum exactly and the convolution contains the complete interval
\(0<y<1\). The NNLO parametrization already leaves the small residual shown in
Table~\ref{tab:moment-sums}.

The finite-lattice test adds a more important complication. Its boundary
choice gives
\[
  \Jvec(b_{\mathrm{grid,max}},t_*)
  =
  (b_{\mathrm{grid,max}},b_{\mathrm{grid,max}}),
\]
but the zero closure sets every larger-\(b\) value to zero. For regular and
off-diagonal terms, this removes the shifted interval
\[
  0<y<\frac{b}{b_{\mathrm{grid,max}}}.
\]
For a diagonal plus distribution, however, the effect is not simply an
omitted interval: the shifted real term is removed while the virtual
self-subtraction proportional to \(\Jvec(b,t)\) remains. At the endpoint this
is a discontinuity at \(y=1\), regulated numerically by \(\Delta\ell\).

The lattice deviations below therefore combine three effects:
\begin{itemize}[leftmargin=1.5em]
  \item incompatibility between the nonzero \(J=b\) endpoint and sharp zero
  closure, including the plus-distribution endpoint artifact;
  \item finite-\(\Delta\ell\) convolution quadrature;
  \item the small NNLO momentum-sum residual of the parametrized kernels.
\end{itemize}
Consequently, this lattice study is a stress test of the closure and
discretization, not a clean analytic validation of the full solver.

\subsection{Large-\texorpdfstring{\(b\)}{b} closure check}

To probe closure sensitivity, \(b_{\mathrm{grid,max}}\) was increased from 30
to 300 while approximately preserving \(\Delta\ell\): the two grids used
\((N,b_{\mathrm{grid,max}})=(1000,30)\) and \((1223,300)\). For the LO upper
triangle and \(b\le0.03\), the RMS errors changed as follows:
\begin{equation}
\begin{array}{c|cc}
b_{\mathrm{grid,max}} & \text{quark RMS} & \text{gluon RMS}\\
\hline
30  & 0.232\% & 0.567\%\\
300 & 0.041\% & 0.056\%
\end{array}
\end{equation}
Moving the closure boundary ten times farther away substantially reduces the
upper-region error. This demonstrates strong closure sensitivity, but it does
not by itself isolate the time marcher or remove the endpoint discontinuity.

\section{What has and has not been validated}

\subsection{Validated}

\begin{itemize}[leftmargin=1.5em]
  \item On the local diagonal-kernel problem with \(b_*(b)=b\), the forward and
  backward updates use the correct sign and boundary values.
  \item Euler exhibits first-order convergence on that problem.
  \item Midpoint RK2 exhibits second-order convergence on that problem.
  \item The quark--gluon channel orientation is consistent with the momentum
  sum rule.
  \item The implemented LO kernels satisfy the \(N=2\) sum rule at roundoff,
  the NLO residual is negligible at the integration tolerance, and the NNLO
  parametrization leaves a residual of order \(10^{-8}\) at \(\as=0.01\).
\end{itemize}

\subsection{Remaining numerical limitations}

\begin{itemize}[leftmargin=1.5em]
  \item A nonzero value at \(b_{\mathrm{grid,max}}\) is incompatible with the
  sharp closure for diagonal plus distributions. The \(J=b\) lattice
  diagnostic deliberately violates this condition.
  \item The present lattice convolution is lower-order than RK2 and can
  dominate the total error.
  \item The local test does not exercise nonlocal channel coupling, a nonlinear
  \(b_*\) curve, or all lower-region midpoint dependencies.
  \item Refining \(\ell\) and \(t\) simultaneously does not by itself separate
  spatial quadrature error from time-integration error.
  \item The two diagnostic scripts print measurements but contain no asserted
  pass/fail thresholds.
\end{itemize}

\section{Interpretation and recommended next steps}

The diagnostics support the following narrower conclusions:
\begin{enumerate}[leftmargin=1.5em]
  \item The local upper and lower updates have the expected integration order
  on an affine boundary line.
  \item The physical kernel channel mapping and momentum sums pass a direct
  continuum-moment check to the residuals shown in
  Table~\ref{tab:moment-sums}.
  \item The \(J=b\) lattice results reveal substantial closure and
  discretization sensitivity; they do not prove the complete nonlocal
  evolution correct.
\end{enumerate}

The most useful next improvements are therefore:
\begin{enumerate}[leftmargin=1.5em]
  \item enforce a vanishing endpoint or replace the sharp closure by a
  continuous large-\(b\) tail model;
  \item add a manufactured nonlocal triangular problem with a nonlinear
  \(b_*(b)\) curve and a known solution;
  \item improve the \(u\)- or \(y\)-quadrature while preserving the
  plus-distribution subtraction;
  \item allow extra \(t\) substeps at fixed \(\ell\) spacing, so temporal and
  spatial convergence can be measured independently;
  \item convert the diagnostic scripts into asserted regression tests with
  documented tolerances.
\end{enumerate}

\section{Reproducibility}

The calculations were run with Julia 1.11.6 and 20 Julia threads. From the
repository root, the environment and asserted regression suite are:
\begin{verbatim}
cd "Numerical RG"
julia --project=. -e "using Pkg; Pkg.instantiate()"
julia --project=. --threads=auto test/runtests.jl
\end{verbatim}

The local convergence and direct moment diagnostics are:
\begin{verbatim}
julia --project=. --threads=auto test/analytic_validation.jl
julia --project=. --threads=auto test/momentum_sum_check.jl
\end{verbatim}

The lattice-refinement and closure rows in this report are reproduced with:
\begin{verbatim}
julia --project=. --threads=auto test/analytic_validation.jl `
    500:30 1000:30 2000:30 1223:300
\end{verbatim}
The regression suite contains 262 asserted checks, all of which passed. The
analytic and momentum scripts are diagnostic only: successful process exit
does not imply their printed residuals met a threshold.
